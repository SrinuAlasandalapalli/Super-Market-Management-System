# Super-Market-Management-System

Supermarket Management System (Java)
Overview

The Supermarket Management System is a Java-based console application that helps manage products and billing in a supermarket. The system allows users to view available products, purchase items, and generate the total bill.

This project demonstrates the use of Java programming concepts such as classes, objects, arrays, loops, and user input handling.

Features

Display available products

Purchase products

Calculate total bill

Update product quantity after purchase

Simple menu-driven interface

Technologies Used

Programming Language: Java

Concepts Used:

Classes and Objects

Arrays

Loops

Conditional Statements

Scanner Class for user input

System Requirements

Java Development Kit (JDK 8 or above)

Any Java IDE (Eclipse, IntelliJ IDEA, NetBeans) or command line

Basic knowledge of Java programming
